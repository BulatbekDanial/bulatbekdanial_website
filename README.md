# Сайт-портфолио: запуск на своём хостинге

Что внутри:

- `index.html` — весь сайт одним файлом.
- `api/` — серверные функции: сохранение правок, фото, вход по коду, счётчик посещений, гостевая книга, форма «Написать мне», необязательный AI-ассистент.
- `lib/util.js` — общий код функций.

Сайт рассчитан на Vercel и базу Upstash Redis (у обоих есть бесплатный тариф).

## Запуск: 5 шагов

1. **GitHub.** Создай новый репозиторий (можно приватный) и загрузи в него содержимое этой папки.
2. **Vercel.** Add New → Project → выбери этот репозиторий → Deploy. Настройки сборки менять не нужно.
3. **База данных.** В проекте на Vercel: Storage → Create Database → Upstash (Redis) → создай базу и подключи её к проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
4. **Код админа.** Settings → Environment Variables → добавь `ADMIN_CODE` со своим секретным кодом. Код хранится только на сервере, в файлах сайта его нет.
5. **Redeploy.** Deployments → последний деплой → Redeploy, чтобы переменные применились.

После этого открой сайт, нажми **Admin** в самом низу, введи код и редактируй с любого устройства.

## Как это работает

- **Вход по коду.** Код проверяет сервер. После 8 неверных попыток за 15 минут вход с этого адреса временно блокируется.
- **Счётчик посещений.** Виден в окне Admin: всего, сегодня, за 7 дней. Один визит считается один раз за сессию браузера, твои устройства с введённым кодом не считаются. IP-адреса не сохраняются.
- **Гостевая книга.** Запись посетителя появляется на сайте только после того, как ты нажмёшь «Опубликовать» в окне Admin.
- **Форма «Написать мне».** Сообщения приходят в окно Admin. Уведомлений на почту нет, заглядывай туда сам.
- **Фото.** До 20 фото в галерее, каждое сжимается автоматически.

## AI-ассистент (необязательно)

Кнопка «Ask AI about me» появится, только если добавить переменную `ANTHROPIC_API_KEY` с ключом Anthropic API. Каждый ответ оплачивается с этого ключа; стоит ограничение 20 вопросов в сутки с одного адреса. Без ключа кнопки просто нет.

## Свой домен

Settings → Domains в проекте на Vercel.

## Если что-то не работает

- Правки не сохраняются, а сайт показывает исходные тексты: база не подключена (шаг 3) или не сделан Redeploy (шаг 5).
- Admin пишет «Не получилось проверить код»: не задана переменная `ADMIN_CODE` или не сделан Redeploy.
